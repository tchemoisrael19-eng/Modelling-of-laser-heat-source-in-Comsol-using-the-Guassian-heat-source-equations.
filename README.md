# Modelling of a Gaussian Laser Heat Source in COMSOL

## Overview

This repository presents the modelling and simulation of a laser heat source in COMSOL Multiphysics using the Gaussian heat source formulation. The project demonstrates how a Gaussian-distributed laser beam can be represented as a heat input and applied to a material domain to study temperature distribution and thermal behavior.

The work is intended for students, researchers, and engineers interested in laser-material interactions, heat transfer modelling, additive manufacturing, welding simulations, and thermal analysis.

## Project Objectives

* Implement a Gaussian laser heat source model in COMSOL Multiphysics.
* Simulate heat transfer induced by laser irradiation.
* Analyze the resulting temperature distribution.
* Visualize thermal gradients and heat-affected zones.
* Provide sufficient documentation for reproducing the simulation results.

## Reproducing the Results

1. Review the technical document located in the `Technical_Document` folder.
2. Create the geometry according to the provided specifications.
3. Define the material properties.
4. Implement the Gaussian heat source equation.
5. Apply the boundary conditions described in the document.
6. Generate the mesh.
7. Run the simulation.
8. Compare the resulting temperature distribution with the provided screenshots.
